## Part 9.2

### TD-9.2-01

- 编号：TD-9.2-01
- 问题：普通账号 JWT 尚无 `aud`/`iss`，使用对称 HS256；完整 refresh / key rotation / 生命周期策略仍未实现
- 等级：Medium
- 当前状态：部分完成；C1 已增加 token_type / scope / User capability / auth_generation；rights JWT 严格校验 aud/iss，Contact 撤销使验证失效。旧无类型账号 token 需重新登录。
- 计划处理阶段：剩余普通账号 aud/iss、refresh、密钥轮换与完整会话生命周期后续处理；C1 不开放客户端 generation 修改 API。

- 问题：User 账号删除、Owner 转移及保留策略仍未定；C2A 已消除 `families.owner_id` CASCADE 的静默删除风险

## Part 9.4

### TD-9.4-01

- 编号：TD-9.4-01
- 问题：Message `sequence = max(sequence) + 1` 非原子，无 `(session_id, sequence)` 唯一约束，并发写入可能重复/乱序
- 等级：Medium
- 当前状态：开放
- 计划处理阶段：C 落实冻结的父记录锁与 (session_id, sequence) UNIQUE；当前仍未实施，必须在依赖并发写入前完成。
